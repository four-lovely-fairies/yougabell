# 떼쓰기는 왜 생길까

만 1세 후반~3세 사이 아이는 자기 의지가 강해지면서 자주 떼를 씁니다. 이는 정상적인 발달 과정으로, "내가 할 수 있다"는 자율성과 "마음대로 안 된다"는 현실 사이의 갈등에서 비롯됩니다.

떼쓰기의 흔한 원인:

- 피곤·배고픔·졸음 같은 신체적 상태
- 자기가 원하는 것을 표현할 언어 능력 부족
- 부모의 관심을 끌고 싶은 정서적 욕구
- 일관되지 않은 규칙으로 인한 혼란

# 떼쓰기 다루는 원칙

## 1. 차분하게 반응하기

부모가 같이 큰 소리로 응대하면 아이의 흥분은 더 커집니다. 부모는 평소보다 더 낮고 천천한 목소리로 말하세요. "엄마는 네가 진정될 때까지 옆에 있을게."

## 2. 감정 인정 + 행동은 분리

"네가 사고 싶었던 거 사지 못해서 속상하구나"라고 감정은 받아들이되, "그렇다고 마트 바닥에 누우면 안 돼"라고 행동의 한계는 분명히 합니다.

## 3. 안전한 공간으로 이동

공공장소에서 떼를 쓰면 주변 시선이 부담스럽습니다. 즉시 화장실·차·집 안 등 자극이 적은 공간으로 옮겨 진정시키세요. 부모도 호흡할 시간을 가질 수 있습니다.

## 4. 진정 후 짧게 이야기 나누기

폭풍이 지나간 후 아이가 안정되면 "아까 어떤 마음이었어?"라고 물어보세요. 아이가 자기 감정에 이름을 붙이는 연습이 됩니다.

## 5. 일관성 유지

부모마다 다르게 반응하면 아이는 규칙을 시험합니다. 한번 "안 돼"라고 했으면 다음에도 같아야 합니다.

# 미리 예방하기

- **충분한 수면·식사** — 떼쓰기의 절반은 컨디션 문제.
- **하루의 흐름 예측 가능하게** — "이제 양치하고 잘 거야" 등 다음 단계를 미리 알려주기.
- **선택지 제시** — "양말 빨간 거 신을까, 파란 거 신을까?" — 통제권을 부분적으로 주면 협력합니다.
- **하루 1번 '특별한 시간'** — 부모와 단둘이 보내는 10~15분. 정서적 허기를 미리 채워줍니다.

# 절대 하지 말 것

- 신체적 처벌·고함
- "그러면 엄마 안 사랑해" 같은 사랑 거두기 위협
- 다른 아이와 비교 ("○○는 안 그러는데")
- 떼를 멈추기 위해 즉시 원하는 것을 주는 것 (다음에도 같은 방식 반복)

## 참고

만 3세 이후에도 떼쓰기 강도가 점점 커지거나 자해·타해가 동반되면 발달 평가나 상담을 받아보는 것이 좋습니다.
