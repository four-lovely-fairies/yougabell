# seed-data — 시드 데이터 소스

DB 초기 적재(`yougabell-api/scripts/import-csv-data.ts`)에 쓰이는 원본 CSV 모음.

## 미션 데이터: 통합본만 사용

| 파일                                                       | 역할                          | import |
| ---------------------------------------------------------- | ----------------------------- | ------ |
| `[youth] 워킹맘 MVP 데이터 가공 - 미션 데이터.csv`         | **통합본 — 유일한 미션 소스** | ✅     |
| `[youth] 워킹맘 MVP 데이터 가공 - 손서현_미션데이터.csv`   | 개별 작업본 (참조용)          | ❌     |
| `[youth] 워킹맘 MVP 데이터 가공 - 오유현_미션데이터.csv`   | 개별 작업본 (참조용)          | ❌     |
| `[youth] 워킹맘 MVP 데이터 가공 - 김성훈_미션 데이터(...)` | 개별 작업본 (참조용)          | ❌     |
| `[youth] 워킹맘 MVP 데이터 가공 - 마일스톤 데이터.csv`     | 마일스톤 소스                 | ✅     |

- **통합본(`미션 데이터.csv`, 480건)이 미션의 단일 진실의 소스.** import는 이 파일만 읽는다.
- **개별 운영자 시트(손서현/오유현/김성훈)는 통합본으로 흡수 완료 → 참조용으로만 보관.** import 대상이 아니다.
- 미션을 추가/수정할 때는 **통합본만** 갱신한다. 개별 시트는 작업 이력 보존용이며 DB에 반영되지 않는다.

> **배경**: 과거 import 스크립트가 통합본과 개별 3개 시트를 모두 적재해 DB에 945건(부분 중복)이 쌓였다.
> 통합본은 개별 시트의 중복·이상 미션을 정리한 480건이므로, 통합본만 단일 소스로 사용하도록 정리했다.
> 정합화 내역: [`yougabell-api`](https://github.com/four-lovely-fairies/yougabell-api) PR #46, 후속 import 정리 PR.
