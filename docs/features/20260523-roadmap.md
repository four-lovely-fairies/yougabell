> 자녀의 현재 월령 기준 **발달 마일스톤**을 4개 영역(사회성·언어·인지·신체) 카드로 보여주고, 인접 월령 탭으로 과거·미래 마일스톤을 미리/되돌아볼 수 있는 페이지. BottomNav 3번째 탭(`로드맵`)의 진입 화면.

## 1. 배경 (Why)

육아벨 v0.1은 홈 화면에 "현재 상황 [ 자아 형성기 ]" 카드 1줄, 미션 1건만 노출한다. 다음 한계가 있다:

- **"내 아이가 지금 어떤 단계인지" 큰 그림이 없다** — 부모는 "지금 이 시기에 무엇을 기대해야 하는가, 무엇이 정상인가"가 가장 궁금. 미션 1건은 "오늘 할 일"일 뿐 큰 그림이 아님.
- **인접 월령 비교 불가** — "지난달엔 무엇을 했어야 했지?" "다음달엔 뭘 준비하지?"를 보려면 별도 탐색이 필요.
- **데이터 출처에 대한 신뢰 부재** — CDC/AAP/국민건강보험/보건복지부 가이드에 기반한다는 사실을 홈에서는 보여주지 못함. 부모가 인터넷에서 본 "카더라"와 구별이 안 됨.

본 기능으로 위 3가지를 한 화면에 묶는다:

1. **현재 상황 카드** — 발달 단계명 + N개월 차 + 한 단락 요약
2. **월령 탭** — 2개월 단위 인접 월령 5개 탭 (좌/우 chevron으로 더 이동)
3. **4개 영역 카드** — 사회성 / 언어 / 인지 / 신체 — 각 카드 안에 마일스톤 bullet들
4. **info icon → tooltip** — 데이터 출처(CDC·AAP·국민건강보험·보건복지부) 안내

## 2. 사용자 시나리오 (What)

- **누가**: 온보딩 완료 후의 사용자 (자녀 ≥ 1명 등록)
- **언제**: BottomNav `로드맵` 탭 클릭 시 (현재 미연결 — 본 기능으로 연결됨)
- **흐름**:

  ```mermaid
  flowchart LR
      H[홈 또는 어디서든] -- BottomNav 로드맵 --> R[로드맵 메인<br/>2516:5324]
  ```

- **수용 기준**:
  - BottomNav `로드맵` 탭이 활성화되고 `/roadmap`으로 라우팅된다
  - 선택된 자녀의 현재 월령에 매칭되는 4개 카테고리 카드가 모두 노출된다 (빈 카테고리 없음)

  - info icon 클릭 시 데이터 출처 tooltip이 토글된다
  - Sub LNB 뒤로가기 → 이전 페이지 (홈에서 왔으면 홈)

## 3. 도메인 영향 — **카테고리 체계 변경 (중요)**

### 3.1 카테고리 마스터 재정의

[`../schema/04-roadmap.md`](../schema/04-roadmap.md)는 구 Figma `851:5028` 기반으로 6종 카테고리 (`emotion`/`education`/`sleep`/`food`/`health`/`play`)를 정의했다. 그러나 신규 Figma `2516:5324`는 **CDC/AAP 발달검사 표준에 가까운 4영역**:

| 신규 ID (제안) | 라벨   | 아이콘 (Figma)   | 카드 색 (제안) |
| -------------- | ------ | ---------------- | -------------- |
| `social`       | 사회성 | `groups`         | 노랑(따뜻함)   |
| `language`     | 언어   | `dictionary`     | 파랑(소통)     |
| `cognitive`    | 인지   | `psychology_alt` | 보라(사고)     |
| `physical`     | 신체   | `barefoot`       | 청록(움직임)   |

> 단순히 라벨만 다른 게 아니라 **분류 체계의 차원이 다름** — 구 6종은 "주제 영역"(수면·음식·놀이 등 활동 카테고리), 신규 4종은 "발달 영역"(CDC milestone domain). 같은 마일스톤을 두 체계로 동시에 표현하기 어려움.

**제안**: 신규 4종으로 **전환** (구 체계 폐기). 미션 카테고리와의 관계는 §3.3 참조.

### 3.3 미션 카테고리와의 관계 — 결정 필요

[`../schema/05-mission.md`](../schema/05-mission.md)의 `Mission.categoryId`도 `MilestoneCategory` 참조. 변경 시 미션 시드 전체 영향. 옵션:

- **A안 (단일 체계)**: 미션도 4종(`social`/`language`/`cognitive`/`physical`)으로 재매핑. 미션 추천 알고리즘 단순. 미션 큐레이션 다양성 ↓ 가능성.
- **B안 (분리 체계)**: `MilestoneCategory`(4종, 발달 영역) ≠ `MissionCategory`(6종, 활동 영역). 두 모델 분리, 미션 추천 시 `Mission.developmentDomains: string[]` (CDC 영역 태그)로 다대다 매핑.
- **C안 (계층)**: 미션 6종은 유지하되, 각 미션을 발달 영역에 다대다 태깅 (`Mission.developmentDomains`).

→ **결정 (2026-05-23): A안 (단일 4종 체계)**. `Mission.categoryId`도 `social`/`language`/`cognitive`/`physical` 중 1개. 기존 미션 시드(6종 기반)는 Phase 1에서 4종으로 재분류. v0.1 출시 전이라 시드 재작성 비용 일회성.

### 3.4 GET /me/roadmap 응답

선택된 자녀의 월령 N (또는 임의 월령 파라미터) 기준 응답:

```ts
type RoadmapResponse = {
  child: {
    id: string;
    name: string;
    ageMonths: number; // 현재 월령
    ageLabel: string; // "4개월 차"
  };
  stage: {
    id: string; // "self-formation"

  monthTabs: number[]; // 탭에 노출할 5개 월령 (예: [2,4,6,8,10])
  monthTabRange: {
    // 페이지네이션 메타
    prev: number | null; // 좌 chevron 클릭 시 이동 (없으면 null = 비활성)

  milestonesByCategory: {
    categoryId: "social" | "language" | "cognitive" | "physical";
    categoryLabel: string;
    iconKey: string; // chip 아이콘
    items: Array<{
      id: string;
      description: string;
      sourceCitations?: { citation: string; url?: string }[];
    }>;
  }[];
  sourceTooltip: {
    text: string; // "CDC, AAP, 국민건강보험, 보건복지부 등 ..."

```

> 카테고리는 **항상 4종 모두** 반환 (빈 카테고리 없음 보장 — CMS 커버리지 룰). 카드 순서는 디자인 순서(사회성→언어→인지→신체) 고정.

#### Milestone 시드 (CDC/AAP 기반)

대상 월령: **2 / 4 / 6 / 9 / 12 / 15 / 18 / 24 / 30 / 36 / 48 / 60 개월** (CDC Act Early 공식 체크포인트). 각 월령 × 4 카테고리 = 48건 시드. 상세 시드는 별도 `prisma/seed/milestones.ts`에서 관리, 본 문서는 4개월차 예시만:

| ageMonths | category  | description                                                                                                                             |
| --------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 4         | social    | 말을 걸거나 들어 올리면 차분해진다. 상대의 얼굴을 바라본다. 아이에게 다가가면 좋아한다. 아이에게 말하거나 미소를 지을 때 미소를 짓는다. |
| 4         | language  | 울음 소리 이외의 소리를 낸다. 시끄러운 소리에 반응한다.                                                                                 |
| 4         | cognitive | 움직임에 따라 상대를 주시한다. 수 초 동안 장난감을 본다.                                                                                |
| 4         | physical  | 머리를 가눌 수 있다. 엎드린 자세에서 팔에 의지해 머리를 든다.                                                                           |

> 1차 시드 작성은 Phase 1 내 별도 작업. Figma 본문 텍스트 그대로 이식 + 누락 월령은 CDC 공식 가이드(https://www.cdc.gov/ncbddd/actearly/milestones)에서 보강.

#### 월령 구간 규칙 — 반열린 `(from, to]` (2026-07-29 확정)

CSV는 단일 시점(2개월, 4개월 …)이지만 그 사이 월령(예: 3개월)이 비면 안 되므로, 임포트가 각 항목을
구간으로 펼친다: **`ageMonthsFrom = 직전 시점`, `ageMonthsTo = 해당 시점`**. (2개월 → `0~2`, 4개월 → `2~4` …)

즉 **마일스톤이 속한 시점은 `ageMonthsTo`** 이고 `ageMonthsFrom`은 직전 시점이다.
따라서 조회 조건은 **양끝 포함(`from <= X <= to`)이 아니라 `from < X <= to`** 여야 한다.

양끝 포함으로 조회하면 경계 월령에서 직전 시점 항목까지 함께 잡혀 **한 탭에 두 시점 분량이 노출**된다.
실제로 159건 중 148건이 인접 두 탭에 동시 노출되는 버그가 있었다 (합계 307건 → 수정 후 159건).
구현은 `yougabell-api/milestones/milestone-age.ts`의 `milestoneAgeWhere()` 한 곳에서만 관리한다 —
로드맵·홈 추천·미션 추천·어드민 필터가 모두 이 함수를 쓴다.

> 0개월만 예외로 양끝 포함. 첫 구간이 `0~2`라 strict 비교로는 아무것도 안 잡힌다.

#### 엔드포인트

| 메서드 + 경로                               | 설명                                                                              | Auth |
| ------------------------------------------- | --------------------------------------------------------------------------------- | ---- |
| `GET /me/roadmap?childId=...&targetMonth=N` | 자녀 1명의 N개월차 로드맵 응답 (§3.4). 둘 다 옵셔널, 기본은 선택 자녀 + 현재 월령 | JWT  |

- `childId` 미지정 시 첫 번째 활성 자녀.
- `targetMonth` 미지정 시 자녀 현재 월령.
- `targetMonth`가 시드 없는 월령이면 **가장 가까운 하단 월령**으로 자동 보정 (예: 5개월 → 4개월). 응답 `targetMonth`는 보정된 값.
- `monthTabs`는 `targetMonth` 중심 5개를 **CDC 체크포인트 리스트(`[2,4,6,9,12,15,18,24,30,36,48,60]`)에서 슬라이딩**. 예: 6개월 선택 → `[2,4,6,9,12]`. 양 끝 도달 시 한쪽으로 치우침 (예: 60개월 선택 → `[24,30,36,48,60]` 5개).
- `monthTabRange.prev`: 5개 윈도우 앞 첫 월령 (좌 chevron). 0개월 이전 없으면 `null`.
- `monthTabRange.next`: 5개 윈도우 뒤 첫 월령 (우 chevron). 마지막 월령 이후 없으면 `null`.

#### OpenAPI export

- 좌/우 chevron 클릭 → `monthTabRange.prev`/`.next`로 `targetMonth` 점프 → 다시 fetch

## 6. 비기능 요구

### 저장 전략

- **읽기 전용 페이지** — PATCH/POST 없음. `GET /me/roadmap` 1회로 모든 데이터 hydrate.
- **월령 탭 클릭 시 재요청** — 캐싱은 v2 검토. 1차는 매번 fresh fetch (Vercel runtime cache 활용은 별도 작업).
- **child 변경 동기화** — 홈에서 선택된 자녀 변경 시 로드맵도 함께 갱신. `getStoredSelectedChildId()` (localStorage) 의존 (홈과 동일 패턴).

### 성능

- 응답 200ms 이하 목표 (페이지당 마일스톤 4개, 텍스트 약 600 바이트).
- 월령 탭 클릭 → 200ms 이내 갱신 (스피너 없이 직접 교체).
- `loading` 상태에서도 카드 placeholder를 보여 layout shift 방지.

### 접근성

- Sub LNB 뒤로가기: `aria-label="뒤로 가기"`
- info icon: `aria-label="데이터 출처 안내"` + `aria-expanded`
- 월령 탭: `role="tablist"` + 각 칩 `role="tab"` + `aria-selected`
- 좌/우 chevron: `aria-label="이전/다음 월령 보기"`, `disabled` 시 `aria-disabled`
- 카테고리 카드: `role="article"` + heading 구조 (h3)

### 분석 이벤트

| 이벤트 키                     | 발생 시점                               |
| ----------------------------- | --------------------------------------- |
| `roadmap_open`                | 페이지 진입 (props: childId, ageMonths) |
| `roadmap_month_change`        | 월령 탭 클릭 (props: from, to)          |
| `roadmap_chevron_navigate`    | 좌/우 chevron 클릭 (props: direction)   |
| `roadmap_source_tooltip_open` | info icon 클릭으로 tooltip 노출         |
